# 三项新需求计划

## 1. 微信一键登录
平台内置登录方式里没有微信（只有 Google / Apple / 微软 / 邮箱），需要自己接入微信「网站应用扫码登录」。

**你需要先准备（我无法代办）：**
- 微信开放平台账号（需企业/机构认证，年审费 300 元）
- 创建「网站应用」并通过审核，拿到 AppID 和 AppSecret
- 授权回调域名需是已 ICP 备案的域名（lovable.app 子域名无法备案，需绑定你自己的备案域名）

**做法：**
- 登录页新增绿色「微信登录」按钮，跳转微信扫码页
- 扫码后回到网站，服务器用 code 换取微信用户身份（unionid/openid）
- 按微信身份查找或自动创建账号并直接登录；昵称、头像存入个人资料
- 原有 Google / 邮箱登录保留
- 在拿到 AppID/AppSecret 之前，按钮先显示但提示「即将开放」

## 2. 创作清单删除单个会话
- 左侧会话列表每一项悬停时出现「⋯」菜单 → 「删除」
- 弹出确认框：「删除后该创作的对话和黑板记录都无法恢复」
- 删除当前打开的会话后，自动跳到下一个会话或新建页
- 只能删除自己的会话

## 3. 首页描述更新
- 四个智能体卡片全部改为「已接入」，补上英语伴学智能体（共 5 张：调度中枢 + 4 个）
- 新增「特色功能」区：共享状态黑板、语音陪伴（中文/英语口语）、1:1 可打印裁剪图纸、四维循证评价、英语词汇卡与知识点图谱进度
- 简介文案与网页标题/描述同步更新

## 技术细节
- 微信：server 路由 `/api/public/wechat/start`（带 state 防 CSRF）与 `/api/public/wechat/callback`；回调里换 access_token 获取 unionid，用后台管理接口按合成邮箱 `wx_<unionid>@wechat.local` 查找/创建用户（自动确认），生成一次性登录链接 token 并在 `/auth` 页 `verifyOtp` 完成登录。新增 `profiles` 表（昵称、头像、wechat_unionid 唯一），RLS 仅本人读写。密钥 WECHAT_APP_ID / WECHAT_APP_SECRET 通过密钥表单添加。
- 删除：先删该会话 messages 再删 sessions（现有 RLS 已限定本人），失效 sessions 查询缓存。
- 首页：更新 `src/routes/index.tsx` 的 agents 数组、功能区和 head()。
