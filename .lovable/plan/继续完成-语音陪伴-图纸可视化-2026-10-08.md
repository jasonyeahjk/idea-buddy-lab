# 继续完成：语音陪伴 + 图纸可视化

## 要做的事（用户能看到的）
1. **聊天页「语音陪伴」按钮**：点一下开始通话，再点结束；通话时显示状态（连接中 / 正在听 / 正在说）和实时字幕。智能体接通后先用温暖的普通话打招呼。
2. **语音回答进入会话**：每轮语音问答（含图纸）保存到当前会话，刷新后能看到。
3. **图纸卡片**：创作辅助智能体画的图在消息里显示为卡片，可放大查看、下载 SVG、按 1:1 打印（毫米尺寸）。
4. **黑板「图纸」栏**：列出本会话画过的图纸摘要。

## 验证
- 运行现有测试 + 图纸尺寸限制测试。
- 浏览器登录后：文字发送"帮我画兔子灯笼的裁剪图"，确认卡片出现、能下载；刷新后仍在。
- 语音：确认通话能建立、开场问候、字幕出现、结束按钮能立即停止。（真实麦克风对话需你在预览中亲自试一次。）

## 技术细节
- 补齐 `live-relay.server.ts` 的客户端委派：校验 token 与会话归属 → Supervisor 路由 → 对应智能体（回答限 120 字），结果写回同一 delegation，并持久化消息与黑板。
- 正式环境：在 `src/server.ts` 处理 `/api/live` WebSocket 升级；预览用已有 `live-vite-plugin.ts`（在 `vite.config.ts` 注册）。
- `useLiveVoice` 在 start 消息中携带 access token 与 sessionId；组件保持挂载，Stop 立即静音并中止。
- 新增 `DiagramCard` 组件：从 `draw_diagram` 工具输入渲染 SVG（viewBox 以毫米计，打印时 width/height 用 mm 单位）；样式 cut/fold/seam/glue/guide 用语义色。
- 工具卡片默认折叠，图纸卡片单独渲染在工具结果下方。
- 在 `AGENTS.md` 记录：语音走 Live 客户端委派复用同一套智能体；图纸以毫米结构化规格存储、前端渲染 SVG。
