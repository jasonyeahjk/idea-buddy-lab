# 借鉴 os-taxonomy + 新增英语伴学智能体

## 一、仓库借鉴点（luw2007/os-taxonomy-beijing，源自 Marble 开源技能图谱）
该仓库把 K-12 学习内容拆成"微知识点"，每个点有：通俗描述、**掌握证据标准**、类型（概念/程序/表征/语言/元认知）、适龄范围，并用**前置依赖图**（hard/soft + 理由）连接，对齐课标（北京版）。可借鉴：
1. **微知识点 + 掌握证据** → 让"循证评价"有标准可依：评价时引用具体知识点的证据条目，而非泛泛打星。
2. **前置依赖图** → 智能体判断学生"还缺哪一步"，推荐下一个可学的点（最近发展区）。
3. **年龄带自适应** → 按学生表现估计水平，调整难度和用语。
4. **课标对齐** → 教师可看到作品对应哪些课标要求。
本次先在英语上落地 1~3，图谱结构做成通用的，以后可扩展到劳动/美术。

## 二、英语伴学智能体（第 4 个智能体）
调度中枢新增"english"意图（如"这个用英语怎么说""我想练英语""帮我用英语介绍作品"），交给**英语伴学智能体**，它读取同一块黑板，用创作主题学英语：
- **创作词汇卡**：从黑板的材料、步骤自动生成中英词汇卡（单词、音标、例句、可点读），聊天中显示为卡片，黑板新增「英语词汇」栏。
- **英语口语练习**：语音陪伴新增"英语模式"开关，用英语对话、温和纠正表达，回答保持简短。
- **知识点图谱进度**：内置一份精简英语微知识点图谱（约 40 个点，覆盖小学到初中：词汇主题、句型、时态、口语功能），每点带掌握证据和前置关系；智能体在对话中记录证据，黑板显示「英语进度」：已掌握 / 学习中 / 推荐下一个。
- **英文作品介绍**：分享阶段帮学生把作品写成英文介绍（分级难度），并给出朗读练习。
- **K-12 自适应**：根据学生表达估计水平（初级/中级/进阶），写入黑板，后续回答随之调整。

## 验证
- 测试：意图路由到英语智能体；图谱前置关系无环；进度合并规则（证据累计达到标准才标"已掌握"）。
- 浏览器登录后：同一会话先聊"做蛋糕"，再说"教我这些材料用英语怎么说"→ 出现词汇卡、黑板英语栏更新；"帮我用英语介绍我的蛋糕"→ 生成分级英文介绍；刷新后仍在。
- 英语语音模式需你在发布后的网站亲自试。

## 技术细节
- `blackboard.ts`：AgentId/Intent 增加 `english`；黑板新增 `englishLevel`、`vocab[]`（word/phonetic/meaning/example）、`englishProgress`（topicId→证据计数/状态）；`applyPatch` 对应合并规则。
- `src/lib/agents/english-taxonomy.ts`：静态微知识点数据（id、名称、描述、evidence、type、ageBand、prerequisites[{id,strength,reason}]）+ `nextRecommended()`。
- `english.server.ts`：streamText + 工具 `update_blackboard`、`add_vocab_cards`、`record_evidence`；支持 extraInstructions（语音英语模式）。
- `supervisor.server.ts` 意图枚举与提示词加 english；`chat.server.ts` 与 `live-relay.server.ts` runners 加入英语智能体；语音英语模式通过 start 消息的 `mode` 字段切换 Live 指令与开场白（英文问候）。
- 前端：`VocabCard` 组件（朗读用浏览器语音合成）、黑板「英语词汇」「英语进度」栏、语音组件加"中文 / English"切换。
- 黑板存于现有 sessions jsonb，无需改表。
- 更新 `AGENTS.md`（知识点图谱为静态数据模块、智能体通过证据工具写进度）与记忆中智能体路线图（5 个智能体）。
